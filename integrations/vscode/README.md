# NeoCoder VS Code 3.1.2 评审接入

本机代码评审入口仍使用原生 `review/start` 完成普通评审。原回合完成后自动打开一轮只读公司规则追评，使用同一会话、同一评审范围和已安装的 [Skill](../../SKILL.md)。普通评审文本作为评审卡片的原样前缀，追加结果位于「公司规则追评」。追评启动失败、取消或缺结果时，卡片继续显示已取得的普通评审。

`reviewFollowup.js` 是接入模块。`neocoder-3.1.2.patch` 记录扩展原有两个文件的修改。两者配套使用，仅针对 NeoCoder VS Code 3.1.2。已安装的 Skill 由 `.neocoder/skills/neo-code-review` 指向本目录所属的 Skill 根目录，后续修改 Skill 正文无需重新打包扩展。

本机 VS Code 启动参数选择已安装的 3.1.2 app-server 和同版本 NeoFlow 认证助手，沿用当前 NeoFlow 会话。CLI 4.2.1 的安装目录不受这条 VS Code 配置影响。扩展更新可能覆盖本地补丁，升级前后按新版本的评审回合协议重新核对。

本版本的自定义代码评审可用 `--commit <40 位 SHA>` 固定提交。正常评审仍接受现有自定义指令及默认的未提交变更范围。

固定提交的追评会从 Git 对象读入本次差异，并根据普通评审成功的源码读取记录补读相关文件和行区间。第二轮直接收到标有 SHA 的材料，有上下文缺口时仍可继续使用当前工具。此接入的宿主补读覆盖固定提交模式，其他模式由原生评审工具读取工作区。
